# 검증 범위

## 실제 MySQL과의 비교 이력

`mysql/src/mysql-compat-report.json`은 실제 MySQL 8.0.46과 학습 엔진을 비교했던 175건의 결과와 소스 해시를 담습니다. 학습 단계의 SQL·상태 비교와 자료형·문자열·집계·오류 등 경계 조건을 포함합니다. 저장소 정리 과정에서 이 결과를 새로 측정한 것처럼 날짜를 바꾸지 않았습니다.

보고서의 소스 해시가 현재 `engine.js`, `mysql-compat.js`, `content.js`와 일치하는지 빌드에서 검사합니다. 개발 중 사용했던 임시 MySQL 서버 데이터와 인증 정보는 포함하지 않습니다.

실제 서버 비교 스크립트는 `mysql/tests/mysql-diff.cjs`에 있습니다. 기본 검사와 CI에서는 실행하지 않습니다. 별도 폐기 가능한 MySQL 8.0.46을 `127.0.0.1:33079`에 준비하고 `CBT_DISPOSABLE_MYSQL=YES`를 명시한 경우에만 실행됩니다. 이 스크립트는 **그 서버의 `store_lab`, `compat_diff` DB를 삭제하고 다시 만듭니다.** 기존 데이터가 있는 서버에서는 실행하지 마세요. 사용자는 `CBT_MYSQL_USER`, 비밀번호는 `CBT_MYSQL_PASSWORD` 환경 변수로 전달할 수 있습니다. 저장소 업로드 과정에서는 실제 서버 비교를 재실행하지 않았습니다.

## 저장소에서 실행하는 검사

`npm test`는 아래 검사를 실행합니다.

| 대상 | 검사 |
| --- | --- |
| 정적 페이지 | 세 경로, 내부 링크, 한국어 메타데이터, JavaScript 문법 |
| SQL 엔진 | 52단계 실행, 자료형·오류·집계 등 회귀 검사 |
| SQL Worker | 실제 내장 WASM 실행, 52단계, 자유 SQL, 네트워크 요청 0건 |
| SQL UI | 단계 진행, 잘못된 SQL, 실행만 하기의 격리, 개념, 자유 DB, 백업·복원·재로딩, 테마 |
| 빅데이터 UI | 336문제 구성, 모든 장·난이도·유형 조합, 초안과 위치 저장 |
| 빅데이터 피드백 | 네 가지 채점 표시와 테마; Worker 응답을 모의한 UI 검사 |
| 종합 문제 | 336문제 중복 없는 순회, 장별 균형, 필터, 저장과 재섞기 |

UI 검사는 jsdom 기반입니다. 실제 브라우저의 화면 배치·렌더링, 모든 운영체제와 모바일 환경까지 검증하는 E2E 검사는 아닙니다. 저장소 정리 시 브라우저 확인 도구에 연결할 수 없어 화면의 육안 검사는 수행하지 못했습니다. HTTP로 받은 배포본과 내부 링크는 별도로 확인했습니다.

## 호환성의 한계

SQL 실행은 SQLite WASM 위의 MySQL 호환 계층입니다. 전체 MySQL의 대체물이 아닙니다.

- 학습 범위의 CREATE/INSERT/SELECT/UPDATE/DELETE, 조건·정렬·집계와 주요 함수에 초점을 맞춥니다.
- 모든 Unicode 정렬 규칙, 임의 정밀도 DECIMAL, JavaScript 안전 정수 범위를 넘는 BIGINT를 완전히 재현하지 않습니다.
- SQL_SAFE_UPDATES의 실제 MySQL 최적화기 판단은 근사 구현입니다.
- 고급 DDL, 뷰, 저장 프로시저, 트리거, 권한, 실제 서버 트랜잭션·동시성 등은 학습 지원 범위 밖입니다.
- 결과 비교 기반 채점은 시험용 채점 서버나 보안 샌드박스가 아닙니다.

175건 통과는 해당 사례의 검증 결과이며 모든 SQL이 MySQL과 같다는 의미로 해석하지 않습니다. 빅데이터 코드 실행은 CDN과 Pyodide 패키지의 가용성에도 영향을 받습니다.
