CHAPTER 06

데이터 가공 — 추출 · 정렬 · 요약 · 합치기

query (행)→[[ ]] (열)→sort_values→groupby + agg→merge / concat
6장의 핵심은 위 메서드를 점(.)으로 이어 붙이는 체이닝. 예: df.query(...).groupby(...).agg(...).sort_values(...)

① 행 추출 — query()

df.query("store == 'A관'")                         # 문자값은 따옴표 안에 따옴표
df.query("store != 'A관'")                         # 같지 않음
df.query("category == '음료' & rating >= 4.7")     # 그리고: & 또는 and
df.query("rating >= 4.5 | quantity >= 2")          # 또는: | 또는 or
df.query("payment in ['카드', '간편결제']")         # 여러 값 중 하나
df.query("payment not in ['현금']")                # 제외

② 열 선택

df['sales']                        # 한 열 → Series
df[['store', 'menu', 'sales']]     # 여러 열 → DataFrame (대괄호 2겹!)
df.drop(columns='menu')            # 열 제거

③ 정렬

df.sort_values('sales')                       # 오름차순 (기본)
df.sort_values('sales', ascending=False)      # 내림차순 → 상위 N개: .head(N)
df.sort_values(['store', 'sales'], ascending=[True, False])

④ 집단별 요약 — groupby() + agg() ★가장 중요

# 방법 1: 이름 붙여 요약 (권장)  새열이름=('원래열', '함수')
df.groupby('store', as_index=False).agg(
    총매출=('sales', 'sum'),
    평균평점=('rating', 'mean'),
    주문건수=('sales', 'count')
)

# 방법 2: 한 열에 여러 통계
df.groupby('store')['sales'].agg(['mean', 'sum'])

# 여러 기준으로 묶기
df.groupby(['store', 'location']).agg(총매출=('sales', 'sum'))
요약 함수의미
'mean' / 'median'평균 / 중앙값
'sum' / 'count'합계 / 개수(빈도)
'min' / 'max' / 'std'최솟값 / 최댓값 / 표준편차
as_index=False → 묶은 열이 인덱스가 아닌 일반 열로 남음 (8장 그래프에 필수). .reset_index()도 같은 효과.

⑤ 데이터 합치기

가로 합치기 — merge

기준 열(key)로 열을 붙임
pd.merge(cafe, store, how='left', on='store')

세로 합치기 — concat

행을 이어 붙임
pd.concat([cafe, event], ignore_index=True)

CHAPTER 07

데이터 정제 — 결측치 · 이상치

isna().sum()→dropna / fillna→규칙 기반 이상치→IQR 이상치→삭제·대체·유지+표시

① 결측치 확인

df.isna()                                   # True/False 표
df.isna().sum()                             # ★ 열별 결측치 개수
df.columns[df.isna().sum() > 0]             # 결측치 있는 열 이름
df['department'].value_counts(dropna=False) # NaN 포함 빈도
df['col'].notna()                           # 결측 아니면 True

② 결측치 제거 — dropna()

df_basic = df.dropna(subset=['study_hours', 'sleep_hours'])   # ★ 필요한 열 기준만
len(df) - len(df_basic)                                        # 제외된 행 수
그냥 dropna()가 위험한 이유: 분석에 쓰지 않는 열의 결측치 때문에 행 전체가 삭제 → 멀쩡한 데이터까지 버려지고 표본이 줄어 결과가 편향될 수 있음.

③ 결측치 대체 — fillna()

df_app = df.copy()
df_app['study_hours'] = df_app['study_hours'].fillna(df_app['study_hours'].median())  # 중앙값
df_app['math']        = df_app['math'].fillna(df_app['math'].mean())                  # 평균
df_app['department']  = df_app['department'].fillna(df_app['department'].mode()[0])   # 최빈값 ([0] 필수!)
대표값언제 쓰나
평균 mean()극단값이 없는 숫자 데이터
중앙값 median()극단값이 있는 숫자 데이터 (극단값 영향 적음)
최빈값 mode()[0]범주형(문자) 데이터 — mode()는 Series라서 [0]으로 첫 값 꺼냄

④ 규칙 기반 이상치 (정상 범위를 알 때)

df.query('score < 0 or score > 100')               # 이상치 찾기
df['score'].between(1, 5)                          # 1 ≤ x ≤ 5 이면 True (양 끝 포함)
df[~df['satisfaction'].between(1, 5) & df['satisfaction'].notna()]   # ~ = NOT

# 범위 밖 값 → NaN
df['score'] = np.where(df['score'].between(0, 100), df['score'], np.nan)

# 특정 오류값만 교체
df['commute_min'] = df['commute_min'].replace(999, np.nan)

⑤ IQR 통계적 이상치

Q1  = df['steps'].quantile(0.25)
Q3  = df['steps'].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df['steps'] < lower) | (df['steps'] > upper)]          # 추출
df['steps_outlier'] = (df['steps'] < lower) | (df['steps'] > upper)   # 유지+표시 열

⑥ 처리 판단 기준

상황처리예시
명백한 입력 오류대체 (NaN)commute_min=999, 범위 밖 만족도
실제 가능한 극단값유지+표시steps IQR 이상치 (실제로 많이 걸었을 수 있음)
확인 불가한 값유지+표시 후 확인department='기타X'
최종 체크리스트
  • 결측치를 isna().sum()으로 확인했다
  • 분석에 필요한 열만 선택하여 dropna()를 사용했다
  • fillna()에서 평균·중앙값·최빈값 선택 근거를 생각했다
  • 값의 정상 범위로 규칙 기반 이상치를 찾았다
  • IQR로 통계적 이상치를 탐색했다
  • 이상치를 무조건 삭제하지 않고 실제 가능성과 분석 목적을 함께 판단했다
